# Kras — учебные проекты

Общий репозиторий содержит три самостоятельных задания на Rust. Исходный код,
тесты, конфигурация, документация и финальные результаты находятся рядом с
каждым приложением; подробности и ограничения описаны в проектных README.

## Проекты

| Проект | Назначение | Основные результаты |
|---|---|---|
| [Aeroporty](Aeroporty/README.md) | Проверяемый сбор, валидация и экспорт мирового набора аэропортов | `Aeroporty/output/release/` — CSV, JSON, TOML, YAML, манифест и отчёт проверки |
| [Inflyaciya](Inflyaciya/README.md) | Наблюдение за ценами учебной продуктовой корзины и расчёт индекса инфляции | `Inflyaciya/output/`, текущая история `Inflyaciya/data/inflyaciya.sqlite3` |
| [Vybory](Vybory/README.md) | Сбор и проверка протоколов УИК выборов Государственной Думы 2026 года | `Vybory/output/2026/`, включая общий и территориальные CSV, схемы, отчёт и SHA-256-манифест |

## Требования и проверка

Установите актуальный Rust stable. Каждый проект является отдельным Cargo
package и проверяется из своего каталога:

```powershell
cd Aeroporty # затем аналогично Inflyaciya и Vybory
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test
cargo build --release
```

Основные команды запуска приведены в README соответствующего проекта. Сетевой
массовый сбор для обычной проверки репозитория не требуется: готовые результаты
уже включены.

## Структура данных

- `Aeroporty/src/`, `tests/`, `data/` — код, тесты и декларативные данные;
  `output/release/` — проверенный релиз 1.0.0.
- `Inflyaciya/src/`, `config/`, `research/` — приложение, закреплённая корзина и
  исследовательские отчёты; `output/` и текущая SQLite содержат результаты.
- `Vybory/src/`, `tests/`, `migrations/`, `docs/` — приложение и документация;
  `output/2026/` — полный набор для сдачи и проверки.

## Что не включается в Git

Исключаются только воспроизводимые или локальные рабочие материалы: Cargo
`target/`, временные файлы, скачанные сетевые кэши, промежуточные кандидаты
Aeroporty, рабочая SQLite и исторические архивные копии Vybory, резервные копии
Inflyaciya и локальные журналы. Эти файлы не удалены, кроме однозначно
восстанавливаемых `target/`.

Для точного автономного пересчёта Aeroporty нужны сохранённые снимки источников,
перечисленные в [Aeroporty/REPRODUCIBILITY.md](Aeroporty/REPRODUCIBILITY.md).
Они остаются локально и не входят в обычный Git из-за размера и сторонних
бинарных документов; финальный релиз и его контрольные суммы включены полностью.

Для Vybory заполненная рабочая база не нужна, чтобы собрать или протестировать
приложение. Новое рабочее состояние создаётся миграциями и командами `discover`
и `run`; готовый результат можно изучать напрямую в `output/2026/` без базы.

## Контроль целостности

- `Aeroporty/output/release/manifest.json` содержит SHA-256 релизных файлов.
- `Vybory/output/2026/manifest.json` содержит SHA-256 2 759 файлов поставки.
- `.gitattributes` запрещает преобразование окончаний строк внутри финальных
  наборов, поэтому указанные SHA-256 сохраняются после clone на Windows.
- Подробная инвентаризация и решения по хранению находятся в
  [git-preparation-report.md](git-preparation-report.md).
- Фактическая очистка записана в [git-cleanup-log.md](git-cleanup-log.md).
